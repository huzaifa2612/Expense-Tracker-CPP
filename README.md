# Personal Expense Tracker 💰📊

A simple, efficient, console-based Personal Expense Tracking application built in C++. This project demonstrates the practical use of file handling (`fstream`) and string manipulation in C++ to store and retrieve user data persistently.

## 🚀 Features
* **Add Expenses:** Easily log new expenses by entering the item type and price.
* **View Expenses:** Display a formatted list of all previously recorded expenses.
* **Calculate Total:** Automatically calculates and displays the sum of all expenses logged in the system.
* **Data Persistence:** All records are securely saved to a `data.csv` file, ensuring data is not lost after the program closes.
* **Input Validation:** Robust handling of invalid inputs (e.g., entering text instead of numbers for price) using input buffer cleaning.
